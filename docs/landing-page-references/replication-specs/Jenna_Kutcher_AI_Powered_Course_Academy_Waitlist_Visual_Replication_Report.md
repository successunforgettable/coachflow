## 12. Typography

### Page-specific behaviour

- **OBSERVED:** high-contrast fashion/editorial serif controls the page’s emotional voice. It appears in all-caps manifesto headlines, title case outcome cards, oversized pull quotes and large objection prompts.
- **OBSERVED:** utilitarian sans handles body copy, bullet details, button labels, value tags and explanatory sections.
- **OBSERVED:** serif headings use relatively tight line spacing and intentional short line breaks; they behave as shapes.
- **OBSERVED:** coral/burgundy type on cream/peach fields repeatedly signals important promises. White serif on mustard/coral creates dramatic testimonial/CTA interruptions.
- **OBSERVED:** uppercase condensed sans appears in eyebrow labels and CTAs.
- **OBSERVED:** selective bold and underline inside sans paragraphs create scan paths; emphasis is not solely colour-based.
- **OBSERVED:** no dominant handwritten script treatment is evident.
- **UNKNOWN:** exact font families.

### Mobile type behaviour

The serif remains large rather than collapsing to generic mobile heading scale. Lines wrap aggressively into narrow, poster-like stacks. Body copy becomes a single readable measure, while value/bonus labels remain compact. Long serif headings may occupy most of a mobile screen; that is part of the signature, not an error.

### Five fidelity-killing typography mistakes

1. Replacing the high-contrast serif with a generic geometric sans.
2. Letting display headlines run as wide single lines instead of preserving sculpted line breaks.
3. Applying one uniform heading size throughout; this page relies on dramatic scale shifts.
4. Removing bold/underline micro-emphasis from long sans paragraphs, destroying scan rhythm.
5. Shrinking mobile display type until it behaves like ordinary responsive web copy rather than a poster.

# Nine Creator Scripts — Digital Asset Blueprint
## Attendee voice — for creators who have genuinely done Arfeen's programmes

A **separate set** from the nine Arfeen scripts. Both can run at once.

---

# What changed from the first draft

The first version had creators reporting what Arfeen says, because a hired creator claiming to have attended would be a fabricated testimonial. That constraint is now gone: every creator will be someone who has genuinely done one of his programmes.

So each script now carries a **first-hand moment of recognition** instead of an attribution. "He put four patterns on a screen. Mine was the second one. I knew before he'd finished the sentence" is a real experience, specifically described, and it does far more than "Arfeen Khan says there are four patterns."

**One line held anyway.** They describe the recognition, never a result. No money, no outcome, no "it changed my life" — implied transformation is banned in the compliance research regardless of how true it is. What they describe is an internal moment, which is honest and unregulated.

**And nobody claims to have attended this Sunday session**, because they haven't. They describe Arfeen's work, which they have done, and report Sunday's content factually.

---

# Why this set exists

**A different face is the strongest separator in the research** — talent and demographic breaks semantic grouping more decisively than environment, lighting or format. Nine creators means nine distinct entities before any other variable applies.

**It fills the gap the Arfeen set cannot.** That set has no genuine Unaware coverage, because polished talking-head cannot produce it — lo-fi UGC is called mandatory at that stage. Three of these are phone-shot pieces. The two sets together now span three awareness stages.

**It takes Arfeen off the critical path.** The 6 September campaign ran old creative because new videos arrived the Friday night before a Sunday event.

# Before booking

Confirm which programme each creator did and roughly when. The scripts say "one of Arfeen Khan's programmes" and "I did Arfeen Khan's work" — if a creator can name the specific programme naturally, let them, it is stronger.

Ask each one what they actually recognised. If their real moment differs from the one written, use theirs. A creator delivering their own recollection outperforms one reciting somebody else's, and it removes any question about whether it happened.

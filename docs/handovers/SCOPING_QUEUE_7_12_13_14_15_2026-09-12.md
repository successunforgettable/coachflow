## ITEM 7 — the rewrite engine republishes a landing page with no publish guard
- **Defect.** `complianceRewrites.accept` → `republishLandingPageToKv` (`server/routers/complianceRewrites.ts:278-353`)
  renders the active angle and writes KV (`:352`) with no leftover-token gate, no operator-field hold and no
  compliance gate — all three of which `runLandingPagePublish` applies. `ENABLE_COMPLIANCE_REWRITES=true` on the
  container (verified 2026-09-12).
- **Fires?** Not on current data: the republish only runs when the page has a `publicSlug` (`:762-770`) and 0 pages
  are published; `complianceRewrites` holds 0 rows. **Reachability:** the server does create landing-page rewrite
  suggestions (`landingPages.ts:113`, threshold 100), but **no screen accepts one** — `V2Trail.tsx:159-161` maps only
  headlines and ad copy; `ComplianceWarningPanel` is mounted only on the ad-copy and headline panels; no V1 page calls
  accept. Reachable only by calling the tRPC endpoint directly. **Open, latent.**
- **Shared:** it is the leak route in item 14 and the third piece of the token fix; same file as item 5's unexercised
  `injectRealTestimonials` caller (`:335`).
- **Blast radius:** landing-page rewrites only. Routing it through the real publisher adds three gates and a Worker
  redeploy per accept — an accept can then be REFUSED, which a future UI must handle.
- **Scope:** contained.

## ITEM 12 — the service profile mandates a figure in the lead-magnet topic; the title node carries it
- **Defect.** `services.ts:390` — `hvcoTopicSuggestion` "Must contain a specific number or timeframe…"; written
  unconditionally at `:569` with no provenance. The title node uses `service.hvcoTopic` whenever the caller passes a
  blank topic (`hvcoGenerator.ts:152`); orchestration passes `""` (`orchestration.ts:422`).
- **Fires?** The mandate is unconditional and unchanged — **all 8 surviving services' topics carry a figure**, and
  kit 225's selected title *"The 90-Day First Client Script"* carries its topic's figure. **But** a clean
  demonstration that the figure is INVENTED needs a service whose coach material has no figures: none survives the
  wipe (service 318's "90 days" may be grounded — item 10 found "within 90 days" in service 318 / profile 291), and
  creating one writes rows. Recommended as the first step of the build's pre-flight, on a fresh test service.
- **Where the fabrication does and does not travel:** title rows store the INPUT topic (`hvcoGenerator.ts:223,282`),
  which Auto Mode leaves blank — so the cascade's "Topic:" line (`cascadeContext.ts:474`) and the GoHighLevel push
  (`ghl.ts:854`) are NOT carriers for Auto Mode kits; the carrier is the TITLE itself.
- **Shared:** item 13 selects among item 12's titles; item 15 is the same claim class under CLAUDE.md §14b.
- **Blast radius:** `expandProfile` runs for every new service (both intake screens); the topic is shown/edited in 11
  client screens, V1 included (read-only invariant); the title fallback governs all title generation; provenance on
  the stored value needs a schema column → a migration (invariant 6: isolated from other work).
- **Scope:** structural-leaning — prompt, provenance column + migration, title fallback.

- **Fires? Yes, on surviving data, and not only by tie.** Every surviving service's `long` rows are tied at one

## ITEM 14 — an operator token stored where no gate looks
- **Defect.** Publish gate scans the rendered HTML only (`landingPagePublisher.ts:196`); the intake derives its
  questions from the ACTIVE angle only (`landingPages.ts:361-364`); `updateActiveAngle` (`:715`) is ungated and
  reachable from `V2Trail.tsx` and V1 `LandingPageDetail.tsx` (still routed); the rewrite republish is ungated (item 7);
  eight-plus writers of the angle columns, none token-checked; `cohortLimit`/`cohortCloseDate` are always null, so those
  tokens are always emitted (`landingPageGenerator.ts:1222-1225`).
- **Fires? Yes.** All 6 surviving pages (smoke account, 222–227, event pages) store tokens in all four angles, and
  EACH has tokens that exist only in non-active angles — never asked. LP 227: `COHORT_CLOSE_DATE`, `DIETARY_NOTES`,
  `EVENT_AGENDA`, `OFFER_LINK`, `ROOM_OR_FLOOR_INFO`. None is published, so there is no public exposure today (the
  13 live raw-token pages were removed by the wipe).
- **Shared:** item 7.
- **Blast radius:** `deriveOperatorQuestions` is also used by the kit's facts readiness (`campaignKits.ts:393-465`) —
  change the LP call sites, not the function; the angle-switch gate hits V2 and V1 (V1 must not be edited — a server
  refusal will surface there as an error); a token-free stored copy would be a redesign (stored tokens ARE the
  intake's question list; no single chokepoint across the writers).
- **Scope:** the three-piece fix is contained (a query, a mutation, one republish function); "a stored token is
  impossible" is structural.
